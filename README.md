## SmartVan.io Addon

A centralized tool to manage your Smartvan.io devices as well as install any dependancies like custom cards and the Smartvan.io Integration. You will no longer need to install HACS and then manually instally these separately. Additionally, you will no longer need the resistive sensor card to configure the resistive sensor.


The addon is currently in Beta and is actively being worked on so there may be some minor bugs. Please reach out if you have any issues.
